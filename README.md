# SENTINEL AI
## Intelligent Scam Detection & Threat Intelligence

SENTINEL AI is a machine-learning application for SMS spam
classification and basic URL risk inspection.

### Features
- SMS spam classification
- TF-IDF text feature extraction
- Logistic Regression classifier
- Explainable model signals
- URL structural risk inspection
- Batch CSV analysis
- Model evaluation dashboard
- Downloadable CSV reports

### Technology Stack
Python, Streamlit, Scikit-learn, Pandas, NumPy, Plotly

### Run Locally
pip install -r requirements.txt
streamlit run app.py

### Dataset
UCI SMS Spam Collection.

### Limitations
This is an educational research prototype.
Model predictions and URL heuristic scores are not
verified fraud determinations.
